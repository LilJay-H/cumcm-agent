# 任务：赛题解析与成功标准

只分析题面，不提出未经论证的最终答案。输出包含：

1. **任务重述**：用中文准确列出显式任务与最终交付要求。
2. **子问题分解**：形成 4–7 个可独立验证的子问题，给出输入、输出与依赖关系。
3. **对象与变量**：列出决策变量、状态变量、外生变量、评价指标及单位/量纲要求。
4. **数据需求**：区分题面已有、需要外部检索、可由情景假设给定的数据。
5. **主要困难与风险**：至少覆盖可识别性、时间外推、因果误判、跨职业可比性、机构建议落地性。
6. **候选验证方式**：为每个子问题给出至少一种机械或数据验证。
7. **验收清单**：定义论文完整、结果可信、代码可复现分别意味着什么。

最后给出一张“子问题—证据—模型—产物”的对应表。
