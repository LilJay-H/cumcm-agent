# 2026 ICM F 题端到端示例

本目录保留 CUMCM Agent v0 完成一次端到端基线测试后精选出的公开成果，用于快速了解论文质量、求解程序和机械评估结果。

## 文件

- `paper.pdf`：17 页生成论文。
- `solver.py`：本次运行生成的可复现求解程序。
- `evaluation.json`：结构完整性和一致性机械评估结果。
- [`../../docs/test_report.md`](../../docs/test_report.md)：完整测试过程、已知限制和结论。

## 隐私与复现说明

完整运行目录未纳入 Git，其中包括原题副本、模型输入输出日志、token/费用统计、中间工件和执行日志。若要复现，请按项目根目录 README 的运行说明生成新的 `runs/<run-id>/`。
